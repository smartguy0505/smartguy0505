# Dream

**Local-first software: coding agents, speech, wallets, and small ML systems.**

[Telegram](https://t.me/richard0118) · [codehelm](https://github.com/smartguy0505/codehelm) · [vaultotp](https://github.com/smartguy0505/vaultotp)

I ship tools that run on the machine in front of me. Recent work is a Rust coding agent with explicit permissions, a desktop authenticator that keeps seeds encrypted locally, CPU speech-to-text, and a small team ledger. I also spend time in decentralized ML (Bittensor) and sequence models.

## Selected work

| Project | What it is |
| --- | --- |
| **[codehelm](https://github.com/smartguy0505/codehelm)** | Provider-neutral coding CLI. Plan, build, and review modes; Git-aware tools; resumable sessions; OpenAI, Anthropic, and local Ollama. Rust core with workspace containment, command risk checks, and rollback checkpoints. |
| **[vaultotp](https://github.com/smartguy0505/vaultotp)** | Desktop 2FA app. AES-256-GCM vault, live TOTP codes, QR import, and encrypted backups. Windows installer via GitHub Actions. |
| **[speech-2-text](https://github.com/smartguy0505/speech-2-text)** | Real-time speech-to-text for Windows without a GPU. Moonshine via sherpa-onnx, Silero VAD, PyQt6 UI. |
| **[finance](https://github.com/smartguy0505/finance)** | Till — a team wallet ledger. Admins, leaders, and members record money in and out. Next.js and Prisma. |
| **[bittensor-wallet](https://github.com/smartguy0505/bittensor-wallet)** | JavaScript client for Bittensor identities, staking, and subnet participation. |
| **[BTC-5m-predict](https://github.com/smartguy0505/BTC-5m-predict)** | Transformer trained on 5-minute BTC candles. Data, training, and inference scripts. |
